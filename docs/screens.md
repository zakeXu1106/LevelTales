# 逐页面实现规格

通用：孩子端（P04–P10）全屏、无 Tab、按钮点击区 ≥56pt、正文字号 ≥24pt；家长页用常规 iOS 规范。导航用 NavigationStack + 一个 App 级路由枚举。

## P01 欢迎页（首次启动且无档案时）
- 元素：产品名 LevelTales、一句话 "Stories at exactly your child's reading level."、三行要点（分级/端侧隐私/买断，图标+短句）、主按钮「开始定级 Start」→ P03；次按钮「先选级别」→ P02 家长门 → 手动选级 → 建档进 P04。
- 底部小字隐私说明：不需要账号、不收集孩子数据。
- 已有档案：跳过本页直达 P04。

## P02 家长门
- 触发：P04 右上角家长图标、P13/P14/P11 的一切入口。
- 交互：先长按圆形按钮 2 秒（进度环动画）→ 出现算术题（如 "7 + 5 = ?"）与数字键盘 → 答对进目标页并记会话时间；答错震动+换题。会话 5 分钟、退后台 60 秒失效（AppState 管理，进家长页前统一校验）。

## P03 定级测试
- 答题页：顶部进度（第 n/16 题）；题面区按题型渲染：wordToImage 显示英文词（大字）+ 图片选项网格；audioToImage 先自动播 TTS 再显示图片选项；sentenceComp 显示短句 + 图片或文字选项。点选即判对错（不给孩子对错反馈，只记录并播一个中性音效/动画），自动下一题。
- 引擎：按 PRD M2 自适应规则选题（当前档位、答对升档答错降档、16 题上限、连续 3 同级全对/全错提前结束）；定级计算 = 正确率 ≥70% 的最高级别。
- 结果页（家长向）：级别大字、对齐说明（CEFR/YLE 文案表按级别取）、词汇量范围、按钮「开始阅读」→ 建档 → P04；「调整级别」→ 家长门 → 选级。
- 中途退出（左上角家长长按退出）：不保存。

## P04 孩子端首页
- 元素：问候 "Hi, {{nickname}}"（无小名显示 "Hi!"）、级别徽章（L{{level}} + 本级进度小环，进度 = 本级已见词/本级池总数）、「今日故事」大按钮（插图风）、继续读卡片（有未完成故事时显示标题+「继续读」）、右上角家长入口图标。
- 点今日故事：先查时长上限（已达上限 → 休息页：插图 + "今天读得很多啦，明天再来"）→ 再查免费额度（见 P13 触发规则；额度内）→ P05。
- 额度用完且未解锁：孩子端显示 "今天的故事读完啦" 页（无价格），页内「爸爸妈妈点这里」→ P02 → P13。

## P05 主题选择页
- 12 个主题卡片网格（图标 + 英文名 + 中文小字），单选即确认 → 组装生成参数 → P06。无输入框。

## P06 生成等待页
- 动画（主角跑步/书本翻页 Lottie 替代：用 SF Symbol 动画或帧动画占位即可）+ 文案 "正在为你写故事…"；GenerationPipeline 完成 → 自动跳 P07；全程无失败态（兜底在管线内）。

## P07 阅读页
- 布局：第一页顶部插图；正文分页（每页 2–4 句，按句切分后贪心装页）；底部控制条：上一页/下一页、朗读/暂停按钮、进度点。
- 朗读：点朗读 → SpeechService 整篇逐句朗读，当前句高亮（背景色+下划线）；点任意句 → 单句朗读。
- 点词：弹释义卡（底部半屏）：单词、音标、中文释义、发音按钮；本篇新词带「新词」徽章且正文中该词有圆点下划线。释义来源按 PRD F-05.4 优先级（本地词条 → FM 生成并缓存为运行时词条（存 SwiftData 的 GeneratedEntry 表，字段同 WordEntry）→ 仅发音）。
- 到达末页停留 ≥3 秒 → isFinished=true、写 ReadingSession → 出现「读完啦」按钮 → P08 引导（可跳过跟读直达 P09）。

## P08 跟读页
- 逐句卡片：当前句大字、上句/下句切换、录音大按钮（点开始、再点结束，上限 15 秒自动停）、声波动画。
- 比对完成 → 反馈区：encouragementOnly 显示鼓励语 + 星星动画；flagged 显示标黄词卡（词 + 发音按钮），原句中对应词同步标黄。
- 每句可「跳过」；顶部「跳过跟读」→ P09。完成全部句 → readAloudDone=true → P09。

## P09 理解题页
- 逐题：题干（wordMeaning 题显示目标词大字）、4 个选项大按钮；选错第一次 → 底部提示条显示 evidence 句（"看看这一句：…"）且选项置灰已选错项；第二次选错 → 高亮正确项并自动进下一题；选对 → 鼓励动画 → 下一题。
- 3 题完成 → 回写结果（QuizService/WordRepository）→ P10。

## P10 完成页
- 鼓励语（随机取 5 条内置文案）、本篇新词回顾横滑卡片（词 + 图标/发音）、按钮「回首页」→ P04；若本篇触发晋升条件，仅家长端提示，孩子端不显示。

## P11 家长报告页（门后）
- 区块：级别卡（当前级别、本级进度条、晋升卡条件显示）、本周数据三格（新词数/读完篇数/阅读分钟）、最近 5 篇列表（点进看全文 + 「不再出现」按钮 → isBlocked=true 且后续生成避开同模板）、生词本入口、周报卡（周日生成，T3；平时显示上周周报或占位）。

## P12 生词本页（门后）
- 列表按状态分组（学习中 reviewing / 已掌握 mastered），每行：词、音标、中文、状态与下次复习日；顶部筛选（全部/学习中/已掌握）。

## P13 付费墙页（门后）
- 元素：标题 "解锁 LevelTales 全部内容"、权益清单（无限故事/全部级别/一次买断无订阅/不收集数据/家庭共享）、价格大字（displayPrice + "一次买断"）、购买按钮、恢复购买按钮、购买成功 → 解锁并返回触发前流程（孩子在等则回 P05）。
- 触发点：免费额度用完时从 P04 流程进入；P14 设置页也有「解锁完整版」入口（已解锁则显示已解锁状态）。

## P14 设置页（门后）
- 项：孩子小名（文本框 ≤12 字）、当前级别（选择器 L1–L6，改动需二次确认弹框）、朗读语速（慢/正常分段）、每日时长上限（关/15/30/45 分段）、本地统计查看（M11 计数列表 + 清零）、清除全部数据（红色按钮 → 算术题二次确认 → 执行 F-10.6）、版本与隐私说明（静态文本：不收集数据、无第三方 SDK）。
